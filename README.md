# BasicBalanceSheetApp
I programmed a basic balance sheet app in my 3rd semester for a project. It uses accounting equation (Assets=Liabilities+ Owner's Equity) to validate each transaction. 
This double-entry bookkeeping app allows user to type name of assets, liabilities and equity and then enter the amount. However, in order to move from one component to the other the user must type "done".  
It further evaluates whether the asset side is equal to the liability side or not.
It gives a warning if the balance sheet is not equal.
The app was made on Anaconda using Python language. It includes dictionary, if-else, break and for loop.
